Phantom Identity

A browser-fingerprint randomizer for Chrome — a small privacy tool built to make tracking and cross-site identification harder.

Security & Privacy Research Project

About

Phantom Identity is a Chrome extension focused on browser privacy. It randomizes identifying signals such as the user-agent string, screen resolution, timezone, and Canvas/WebGL fingerprints, aiming to reduce a browser's ability to be tracked or uniquely identified across sites.

This is a security-focused project by kryptbakar. For the full source and build details, see the repository below — a packaged snapshot of the project is also available as phantom-test.zip.
